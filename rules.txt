[КОНТЕКСТ ПРОЕКТА]
Перед вами исходный код веб-каталога аниме AnyRainy (папка animecite).
- Проект — демонстрационный стенд (демо-версия) для защиты перед учебной комиссией.
- Сайт не хранит видеофайлы локально: метаданные (названия, постеры, синопсисы, жанры, рейтинг) подтягиваются через REST API, воспроизведение — через внешние балансеры.
- Готовая вёрстка и клиентская логика уже реализованы; доработки должны вписываться в существующую структуру, а не переписывать проект с нуля.

[СТРУКТУРА РЕПОЗИТОРИЯ]
- index.html — разметка SPA: навигация, каталог, страница просмотра, модалки (аккаунт, избранное, админка), мобильное меню, стили (Tailwind CDN + кастомный CSS).
- app.js (~3600+ строк) — вся фронтенд-логика: каталог, поиск, плееры, авторизация, комментарии, i18n, админ-панель.
- server.js — минимальный Node.js HTTP-сервер (порт 3456): раздача статики + прокси POST /kodik-proxy → kodikplayer.com/ftor (обход CORS) + прокси GET /img?url= для постеров (обход DPI-блокировки CDN в РФ).

Запуск локально: node server.js → http://localhost:3456

[АРХИТЕКТУРА (КАК УЖЕ СДЕЛАНО)]
Каталог и метаданные:
- Jikan API v4 (прокси к MyAnimeList): топ, поиск, пагинация, жанры, эпизоды.
- Онгоинги на главной: AniLibria API (anilibria.top, российский хостинг/CDN, работает без VPN), fallback — Jikan /seasons/now.
- Постеры проксируются через локальный /img (помогает в РФ без VPN); на клиенте — хелпер proxyImg().
- Фронтенд-библиотеки (Tailwind, Lucide, hls.js, EmailJS) и шрифт Inter лежат локально в vendor/ — внешние CDN не используются (работает без VPN). НЕ возвращать CDN-ссылки.
- Перевод синопсисов: MyMemory API (для RU и других не-EN языков).
- Дополнительно: русские названия через Kodik API (работает в РФ); MyMemory как запасной вариант.

Плееры (переключение серверов в UI, константа AUTO_SERVERS):
- Kodik RU — кастомный HLS-плеер (hls.js + <video>), запрос ссылок через Kodik API и /kodik-proxy; fallback — iframe 480p.
- 4K (AniLibria) — API anilibria.top, свой плеер на HLS.
- Megaplay / Megaplay DUB — внешние URL, встраивание через <iframe> (buildIframe).

Пользовательские данные (без серверной БД):
- localStorage: пользователи (anistream_users), сессия, профили (anyrainy_profile_*), избранное, комментарии, лайки.
- EmailJS — подтверждение email и сброс пароля при регистрации.
- Cookie: язык интерфейса (anyrainy_lang).

Маршрутизация в браузере:
- history.pushState: /anime/{malId}, профили пользователей.

UI/UX уже реализовано:
- Тёмная тема, RU/EN (STRINGS + data-i18n), адаптив (мобильная нижняя навигация).
- Бесконечная прокрутка каталога, фильтр жанров, избранное, комментарии с ответами.
- Секретная админ-панель (4 тапа по заголовку модалки «Аккаунт»): статистика, экспорт/импорт JSON, очистка комментариев.

[ТЕХНИЧЕСКИЙ СТЕК (ФАКТИЧЕСКИЙ)]
- Фронтенд: HTML5, ванильный JavaScript (ES6+), без сборщика и npm.
- Стили: Tailwind CSS (CDN), шрифт Inter, иконки Lucide.
- Видео: hls.js, нативный <video>, <iframe> для внешних плееров.
- Бэкенд: Node.js (встроенные модули http, https, fs, path, url) — только статика и прокси Kodik.
- Хранение: localStorage в браузере (не SQLite, не серверная БД).
- Внешние CDN: EmailJS, Tailwind, Lucide, HLS.js, Google Fonts.

[ЧЕГО В ПРОЕКТЕ ПОКА НЕТ]
- Python / Flask / FastAPI / SQLite — не используются; не предлагать их как текущий стек без явной просьбы мигрировать.
- Таблицы movies и players в БД — не реализованы; каталог живёт в памяти (animeData) + кэши запросов.
- Монетизация (CPA, Popunder, рекламные скрипты) — не интегрирована; при необходимости добавлять как отдельную учебную задачу-заглушку.

2. Минимальный diff: не раздувайте проект фреймворками и лишними зависимостями, если задачу можно решить в текущей архитектуре.
3. Новый серверный функционал — по умолчанию расширяйте server.js (прокси, API-обёртки); миграция на Python — только по явному запросу.
