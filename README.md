# AnyRainy — Эни рейни

> Сайт для просмотра аниме в отличном качестве.

AnyRainy — это современный, быстрый и удобный веб-сайт, созданный для всех любителей аниме. Смотрите любимые тайтлы в высоком разрешении, с отличным звуком и без лишних преград.

## ✨ Особенности проекта

* **Высокое качество:** Стриминг видео вплоть до 1080p и 4K.
* **Умный поиск:** Быстрый поиск по названиям, жанрам и тегам.
* **Адаптивный дизайн:** Сайт идеально работает на смартфонах, планшетах и ПК.
* **Избранное:** Возможность сохранять тайтлы и отслеживать прогресс просмотра.

## 🛠 Стек технологий

* **Frontend:** Rust, HTML
* **Backend:** Javascript
* **База данных:** 1С Предприятие 8.3
* **Плеер:** Кастомизированный HTML5 видеоплеер
